# al-Bidāya wa al-Nihāya — animated series

Remotion project for the weekly animated history series based on Ibn Kathīr's *al-Bidāya wa al-Nihāya*.

- `src/` — video compositions
- `.github/workflows/render.yml` — renders a composition on GitHub Actions (Actions tab → "Render video" → Run workflow); the MP4 is attached to the run as an artifact.

Never commit API keys or passwords to this repository.
